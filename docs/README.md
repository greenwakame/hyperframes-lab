# ナレッジベース

このドキュメントは、greenwakame Profile PVの実制作で得た判断と手順を、次の作品にも使える形に整理したものです。初めて読む場合は、次の順番を勧めます。

1. [制作環境](environment.md) — 実際に使用したマシンとツールのバージョン。
2. [はじめ方](getting-started.md) — `npx`を必須としないローカル環境とコマンドの使い方。
3. [制作フロー](workflow.md) — 設計から人の目による確認、納品までの判断点。
4. [アニメーション設計](animation-design.md) — v5で起きたspriteの不連続性と、v6で有効だった方法。
5. [検証とrender](validation-and-render.md) — `check`で分かることと、その後に確認すべきこと。
6. [GitHub向け動画](github-delivery.md) — masterと公開用ファイルを分けた理由と、今回のencode例。

エラーに遭遇したときは[トラブルシューティング](troubleshooting.md)を参照してください。作品全体の経緯は[greenwakame Profile PVの制作事例](../case-studies/greenwakame-profile-pv/README.md)に、動作原理を切り出した実行可能な例は[こちら](../examples/stable-sprite-ui-reaction/README.md)にあります。
