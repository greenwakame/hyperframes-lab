# 制作事例

各事例には、完成物、制作過程、判断と失敗、検証結果、poster、最小限のmetadataを置きます。動画がある場合は公開用動画も置きます。次の作品は`case-studies/<slug>/`に独立して追加でき、制作環境全体や途中renderを混ぜずに済みます。

## 最初のFeatured Case

[![greenwakame Profile PVのposter](greenwakame-profile-pv/assets/poster.webp)](greenwakame-profile-pv/README.md)

### [greenwakame Profile PV](greenwakame-profile-pv/README.md)

**Motion Design · 20秒 · 1920×1080 · 30 fps**

ゲーム風のGitHub Profile PV。v5で見つかった視覚的な不連続性をきっかけに、v6では安定したspriteへ身体変形を加える方法に変更しました。[公開用MP4を見る](greenwakame-profile-pv/media/greenwakame-profile-pv-v6-github.mp4)。

次の事例では専用フォルダに記事と`case.json`を作り、公開権利を確認したposterを追加して、この一覧に1件加えます。動画がある場合のみ`video`、`duration`、`resolution`、`fps`を設定します。日本語の案内文は`summary_ja`に記入します。トップの注目映像にする場合は、その1件だけ`featured_video: true`にします。指定がなければ日付が新しい動画を表示します。masterと途中成果物は制作環境に残します。
