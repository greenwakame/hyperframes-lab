# 制作事例

各事例には、完成物、制作過程、判断と失敗、検証結果、poster、公開用動画、最小限のmetadataを置きます。次の作品は`case-studies/<slug>/`に独立して追加でき、制作環境全体や途中renderを混ぜずに済みます。

### [greenwakame Profile PV](greenwakame-profile-pv/README.md)

**Motion Design · 20秒 · 1920×1080 · 30 fps**
