# 再現可能なExample

Exampleは完成PVより意図的に小さくしています。作品固有の絵、プロフィール素材、HyperFrames本体、インストール済みSkillsを複製せず、制作上の原則を一つずつ試せるようにします。

- [安定spriteと遅れて反応するUI](stable-sprite-ui-reaction/README.md) — 一つの幾何学キャラクターに予備動作・ジャンプ・着地を与え、ジェスチャーから120 ms後にUIを反応させます。

このExampleは[greenwakame Profile PV](../case-studies/greenwakame-profile-pv/README.md)と画素単位で同じ映像を作るものではなく、中心的な動きの原則を取り出したものです。
